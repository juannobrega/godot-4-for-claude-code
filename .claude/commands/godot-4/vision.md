Write or revise `.godotspec/vision.md`.

This file exists for one job: to answer "does this system belong in this game?"
when a spec is being written. If it cannot answer that, it is decoration.

## Interview, do not draft

Ask, one at a time. Short answers are fine; invented answers are not.

1. What does the player *do*, minute to minute?
2. What is the fantasy — who does the player get to be?
3. Three pillars. Not features: the things that, if removed, make it a
   different game.
4. What is this game explicitly **not**? Name the adjacent game it will be
   compared to and say where it diverges.
5. What has to be true for the game to be worth playing at all?

## Resolve contradictions out loud

If "relaxing" and "punishing precision" both come up, say so and ask which
wins. An unresolved contradiction in the vision resurfaces as a stalemate in
every combat spec afterwards.

## Keep it short

One page. A vision nobody rereads constrains nothing.
